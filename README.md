# Cisco Packet Tracer

Laboratórios de redes que montei no Cisco Packet Tracer durante os estudos, organizados por tema. Os arquivos `.pkt` abrem direto no Packet Tracer.

## Estrutura

| Pasta | Arquivos | Tema |
|---|---|---|
| `labs-basicos/` | `test1`, `test2`, `test3` | Primeiros laboratórios |
| `lan-e-servicos/` | `test4-lans`, `test5-serverdns`, `test6-serverdhcp`, `test9-redelan` | Redes locais e servidores DNS e DHCP |
| `wireless/` | `test7-networkwireless1`, `test8-networkwireless2` | Redes sem fio |
| `vlans-e-subnets/` | `VLANs`, `subnets`, `complexnetwork1`, `complexnetworkwithVLAN` | Sub-redes, VLANs e topologias mais complexas |
| `projetos/` | `Projeto - Puc Minas` | Projeto de rede (PUC Minas) |

## Como usar

1. Instale o [Cisco Packet Tracer](https://www.netacad.com/) (gratuito com conta Cisco Networking Academy).
2. Abra o arquivo `.pkt` desejado em **File > Open**.
